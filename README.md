# Laboratorio 3 - Streamlit

Laboratorio práctico de Programación Aplicada para publicar en GitHub Pages.

## Contenido

- `index.html` - interfaz principal.
- `styles.css` - diseño visual.
- `app.js` - lógica completa del laboratorio.
- `material/Leccion_3_Guia_Paso_a_Paso_GitHub_Streamlit.pdf` - guía del estudiante.
- `assets/` - carpeta reservada para recursos adicionales.

## Dinámica

El estudiante completa 3 proyectos simulados:

1. Registro de datos personales.
2. Calculadora.
3. Mini dashboard con 5 filas, gráfica y resumen.

Cada proyecto tiene 8 pasos:

1. Crear `app.py`.
2. Guardar `app.py`.
3. Crear `requirements.txt`.
4. Guardar `requirements.txt`.
5. Crear repositorio en GitHub.
6. Subir archivos y hacer commit.
7. Configurar Streamlit.
8. Probar la aplicación.

Total: 24 pasos.

## Publicar en GitHub Pages

1. Cree un repositorio nuevo.
2. Suba `index.html`, `styles.css`, `app.js`, `material` y `assets` a la raíz.
3. Entre a **Settings > Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama `main` y carpeta `/(root)`.
6. Guarde y espere a que GitHub Pages genere el enlace.

## Importante

Este laboratorio es una simulación educativa en HTML/CSS/JavaScript. No ejecuta Python real. La vista de GitHub, Streamlit y las aplicaciones finales está simulada para practicar el procedimiento aprendido.
